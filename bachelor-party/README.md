# Operation Bosphorus — Umang's Bachelor (Istanbul, Nov 14–22, 2026)

Single-file crew hub (`index.html`, no build step). All trip data comes from the verified itinerary (3 Nov 2026).

| Section | What it does |
|---|---|
| The Mission | Countdown to wheels-down at IST, trip facts, sealed daily dispatches (unseal 06:00 Istanbul time), organizer-only personal messages |
| The Crew | Five profiles: codename, one-liner, photo, flights, nights in Istanbul, live points |
| The Intel | Flights, nightly headcount, base + travel times, weather/prayer times, packing list (per device), shared bookings checklist, items to confirm, rain plan, risks |
| The Itinerary | Day picker (auto-selects today), timeline with map links, full-day Google Maps route, attractions, wine route |
| The Challenges | 20 tailored challenges (daily / dares / competitions) + crew-proposed dares; claim, undo, strike, record winners |
| The Vault | Photo/video uploads tagged by trip day, lightbox, inside-jokes wall |
| The Polls | Live voting with bars and voter avatars; anyone can open a vote |
| The Leaderboard | Challenges + daily drops (5 pts/day) + groom's decrees; awards unseal Sun Nov 22 06:00; punishment draw |

## Storage modes
- **Live (shared):** when opened as the published claude.ai Artifact, data is kept in the artifact's shared database and uploads in its asset store. Updates appear live.
- **Offline:** opened anywhere else, everything is saved in that browser only (photos only, downscaled).

## Access
Invite each crew member **by email as Editor** from the artifact's Share menu. Viewers/Commenters and public-link visitors can read but cannot vote, upload or claim points. Do not also enable a public link: it downgrades outside Editors.

Only the artifact owner can write personal dispatch messages (`secrets` collection rule).
